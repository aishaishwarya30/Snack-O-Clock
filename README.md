# NightBite Food Delivery

This is a frontend + backend food delivery website project.

Project contact email: `aishuhsia2@gmail.com`

## How to open only the frontend

Open `index.html` directly in Chrome.

## How to run with backend

1. Install Node.js from `https://nodejs.org/` if it is not already installed.
2. Open this folder in VS Code.
3. Open the VS Code terminal.
4. Run:

```bash
npm start
```

5. Open this link in Chrome:

```text
http://localhost:3000
```

6. Admin dashboard:

```text
http://localhost:3000/admin
```

The backend saves order, franchise, and newsletter data inside `data/db.json`.

## Alternative

Double-click `start-backend.bat`, then open:

```text
http://localhost:3000
```
